Faster, safer downloads, right inside your browser. No program to install.

YDM takes over large downloads and fetches them in several parallel pieces. On sites that limit speed per connection, files arrive several times faster: in our tests, a 24 MB file took 3.4 s with YDM instead of 12.2 s.

FASTER
• Adaptive connections: starts with four and adds more only while the speed keeps rising.
• Shares the browser's six connections per site among its downloads, instead of queueing behind itself.
• Remembers sites that refuse extra connections, and does not insist.
• No slow piece at the end: idle connections help the piece that will finish last.

RELIABLE
• Never loses a download: if a site refuses YDM, the browser downloads the file as usual, and YDM tells you why.
• Resumes after you close the browser, fetching only what is missing, and only if the file on the server is still the same.
• Pause, resume, retry. Speed limit for all downloads together.

SAFE
• Saved through the browser's own download manager: Mark-of-the-Web and the browser's checks apply.
• Programs (.exe, .msi…) are left to the browser by default, so Safe Browsing also checks where they come from.
• SHA-256 of every file, with a box to compare it with the one the site publishes.
• Incognito downloads never go through YDM.

HANDY
• Downloads page with history, search and filters.
• Paste links to download them; download all links of a page, by file type.
• Right-click any link → Download with YDM.
• A notification when a download finishes.
• English and Italian built in; in Chrome, any other language is translated on your device by the browser itself.

PRIVATE
No account, no analytics, no servers. YDM connects only to the sites you download from. Open source (MIT).

Good to know: the extra speed comes from servers that limit each connection. Many large CDNs use HTTP/2, where the browser already uses one shared connection: there YDM is as fast as the browser.
